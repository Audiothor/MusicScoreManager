# Gestion des Partitions

L'onglet **Partitions** est le cœur de votre bibliothèque musicale. Il rassemble toutes vos partitions sous forme de cartes élégantes et intuitives.

---

## 📥 Importer des Partitions

Pour importer de nouvelles partitions :
1. Cliquez sur le bouton **➕ Ajouter** en haut de la page.
2. Choisissez vos fichiers PDF depuis votre gestionnaire de fichiers ou cloud local.
3. Choisissez si vous souhaitez **copier le fichier dans la bibliothèque** (recommandé pour une autonomie totale) ou **lier le fichier d'origine**.

---

## 🔍 Recherche & Tris Intelligents

Vous disposez d'une barre de recherche instantanée et de plusieurs critères de tri :
- **Titre (A-Z / Z-A)**
- **Compositeur** : avec paramètre personnalisable dans les réglages (*Partitions sans compositeur en premier ou en dernier*).
- **Date d'ajout (Récent / Ancien)**
- **Sans étiquette d'abord** : Idéal pour repérer rapidement les morceaux qui n'ont pas encore été classés.

---

## 🏷️ Étiquettes (Tags) Multiples

Vous pouvez créer et associer des étiquettes colorées à vos partitions (ex : *Jazz*, *Classique*, *Trompette*, *Concert Été*) :
- Filtrage rapide par une ou plusieurs étiquettes.
- Attribution en masse via le mode multi-sélection.

---

## ⚙️ Menu Contextuel (3 points ⋮)

Pour chaque partition, le menu contextuel vous permet de :
- **📖 Ouvrir la partition** en mode lecture plein écran.
- **✏️ Éditer la partition** : modifier le titre, compositeur, tempo de référence, tonalité, note/étoiles et étiquettes.
- **📑 Modifier l'assemblage PDF** : réarranger ou faire pivoter les pages.
- **📡 Partager (Wi-Fi Direct)** : envoyer la partition avec options d'annotations et d'audio rattachés.
- **📦 Exporter (.msmscore)** : générer une archive autonome pour échange ou sauvegarde.
- **🏷️ Renommer**
- **🗑️ Supprimer**
