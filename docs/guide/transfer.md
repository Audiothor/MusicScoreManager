# Partage & Transfert sans fil

Music Score Manager propose deux modes puissants pour partager des morceaux sans avoir besoin d'une connexion Internet externe :

---

## 📡 1. Envoi Direct de Tablette à Tablette (Wi-Fi Direct P2P)

Ce mode permet d'envoyer rapidement une partition ou une setlist complète à un collègue musicien.

### Procédure :
1. **Destinataire** : Active le Wi-Fi de son appareil, ouvre l'application dans **Outils > Transfert Wi-Fi Direct** et appuie sur **Recevoir**.
2. **Émetteur** : Dans son menu d'options de partition ou de setlist, clique sur **📡 Envoyer en Wi-Fi Direct**.
3. **Sélection des options** : L'émetteur choisit s'il inclut les annotations manuscrites et/ou les pistes audio rattachées.
4. **Envoi** : L'émetteur sélectionne le destinataire dans la liste des appareils détectés. Le transfert s'effectue à très grande vitesse.

---

## 📱 2. Diffusion de Groupe par QR Code (Multi-Musiciens)

Parfait pour distribuer une partition ou un programme complet à tout un orchestre, une chorale ou un pupitre en quelques secondes !

### Procédure :
1. **L'émetteur** choisit **Mode Diffusion Groupe (QR Code)**.
2. L'application génère un point d'accès Wi-Fi local avec un **QR Code à l'écran**.
3. **Les musiciens** scannent le QR Code avec leur appareil photo ou entrent l'adresse locale affichée dans leur onglet **Outils > Réception**.
4. Le téléchargement se lance simultanément pour tous les membres connectés.
